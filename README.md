# Intent2Data

Intent2Data maps high-level research questions to granular dataset variables by leveraging intent decomposition, structural module retrieval, and LLM context filtering.

This is the hackathon implementation repository.

**Scientific status:** retrieval design validated offline on HRS [STRUCTURAL REACHABILITY]; LLM stages implemented but **no live LLM result exists yet**. Every metric in this repository carries a label defined in `docs/SCIENTIFIC_CLAIMS.md`, the single source of truth for claims. Intent2Data maps concepts to variables; it does not perform causal inference.
